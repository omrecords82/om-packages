# @om/mantis-shared

Shared foundations extracted from CodedThemes **Mantis React TypeScript** (v4.2.0)
for Orthodox Metrics packages.

Contains theme-related `config` enums/defaults, MUI type extensions, color helpers,
and `ConfigProvider` / `useConfig` used by `@om/mantis-theme`.

Source: `om-workshop/templates/mantis-template`.
